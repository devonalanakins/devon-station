## Minimal feature

- `home()` displays a starlit vector companion between owner-local summary signals and the existing Today focus panel.
- Rest / awake is a deterministic **visual-only** browser state, reset on route render. It does not run AI, microphone, camera, network, push, model inference or background timers.
- Two navigation controls invoke **existing owner-bound** Today and Capture actions; Dadog creates no new tasks, data store or permissions.
- Web CSS includes responsive layout, accessible labels and reduced-motion support.
- A separate offline, downloadable Hatch 001 HTML concept was built outside the repo; it is **not** production and it holds only browser-local demonstration focus.
